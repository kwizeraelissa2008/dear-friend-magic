# School Discipline Management System (SDMS)

A secure, mobile-friendly platform for **Ecole des Sciences Byimana** to manage student discipline, incidents, permissions, events, chat, and analytics — with a role-aware AI assistant that can take actions inside the app.

**Live app:** https://kwizeraelissa.lovable.app
